# 🍔 Sabor & Fuego - Food Truck Data Challenge

Sistema de gestión analítica, panel de control administrativo y campaña de email marketing basada en datos para el Food Truck **Sabor & Fuego**.

---

## 📁 Estructura del Proyecto

```text
food-truck-data/
├── index.html              # Menú público interactivo
├── admin.html              # Panel del dueño con KPIs y gestión CRUD
├── css/
│   └── styles.css          # Estilos globales y responsive (CSS Grid / Flexbox)
├── js/
│   ├── app.js              # Lógica de la interfaz pública
│   └── admin.js            # Análisis de datos, KPIs y lógica CRUD
├── data/
│   ├── carta.json          # Dataset de la carta y estructura de costos
│   └── pedidos.json        # Dataset histórico de ventas del mes
└── emails/
    ├── email-01.html       # Campaña Email: Plato Estrella
    ├── email-02.html       # Campaña Email: Hora Feliz / Franja Baja
    └── email-03.html       # Campaña Email: Categoría de Alto Margen
